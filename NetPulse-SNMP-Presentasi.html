BAGIAN 1: PENDAHULUAN

Latar Belakang & Permasalahan

Mengapa Pemantauan Jaringan Mobile Ini Sangat Dibutuhkan di Kampus?

Tantangan di Lapangan

  • Ketergantungan PC/Laptop: Admin NOC harus membuka WinBox atau Web GUI di meja kerja saat memeriksa jaringan.
  • Penanganan Gangguan Lambat: Saat internet gedung down, teknisi seringkali baru tahu setelah ada komplain.
  • Heterogenitas Router: Kampus memakai perangkat berbeda (MikroTik di gerbang, Cisco di server, Ruijie di lab).
  • NMS Berat: Software monitoring server (PRTG/Cacti/Zabbix) memerlukan dedicated server yang mahal.

Solusi NetPulse SNMP

  • Monitoring Portabel: Pemantauan instan cukup dari HP Android teknisi di saku baju.
  • Tanpa Perantara: HP berkomunikasi langsung via UDP Port 161 (SNMP) ke router.
  • Telegram Early Warning: Bot otomatis mengirim pesan ke grup Telegram saat CPU tinggi atau router mati.
  • Universal Multi-Vendor: Satu aplikasi untuk memantau MikroTik, Cisco, Ruijie, dan OpenWrt sekaligus.

BAGIAN 2: CARA KERJA

Arsitektur Sistem & Aliran Data

Bagaimana HP Android Membaca Telemetri Langsung dari Router?

1. Inisialisasi & Request

  • Admin memasukkan IP Router (misal 192.168.88.1) & Community String (public).
  • Aplikasi membentuk paket SNMP GetRequest via protokol UDP Port 161.
  • Pengiriman dilakukan setiap 3 detik secara asinkron (Coroutines).

2. Respons Router

  • Router (MikroTik/Cisco) membalas dengan paket ASN.1 / BER Encoding.
  • Engine membaca OID spesifik: beban CPU, centiseconds uptime, dan akumulasi oktet.
  • Aplikasi menghitung selisih oktet per detik menjadi Kbps / Mbps riil.

3. Rendering & Alert

  • Visualisasi jarum Gauge CPU dan grafik kurva trafik di kanvas Jetpack Compose.
  • Jika beban CPU > ambang batas (contoh 85%), bot Telegram langsung mengirim notifikasi darurat.
  • Semua status tersimpan ke database lokal SQLite/Room di HP.

Pembuktian Validitas Data Riil MikroTik

Daftar OID Resmi MIB yang Diekstraksi dari RouterOS Kampus

Tabel OID Standar RouterOS

  • CPU Load: 1.3.6.1.4.1.14988.1.1.1.3.1.5.1 (mtxrHlProcessorUsage) & fallback 1.3.6.1.2.1.25.3.3.1.2.1.
  • Download Speed: 1.3.6.1.2.1.31.1.1.1.6.1 (ifHCInOctets 64-bit High Capacity) untuk port Gigabit WAN.
  • Upload Speed: 1.3.6.1.2.1.31.1.1.1.10.1 (ifHCOutOctets 64-bit High Capacity).
  • System Uptime: 1.3.6.1.2.1.1.3.0 (sysUpTimeInstance) durasi aktif router.
  • Active Clients: 1.3.6.1.4.1.14988.1.1.1.2.1.1 tabel registrasi wireless / ARP.

Dua Mode Operasional

  • Mode Riil (Simulasi = OFF):
    Menghubungi IP fisik router kampus. Menghasilkan telemetri riil. Jika router mati, status seketika menjadi OFFLINE.
  • Mode Simulasi (Simulasi = ON):
    Sangat berguna untuk demonstrasi di kelas, sidang skripsi, atau saat laptop/HP tidak sedang terkoneksi ke Wi-Fi kampus.

BAGIAN 5: KEAMANAN

Keamanan & Sistem Login Admin

Melindungi Akses Konsol Jaringan dari Pihak yang Tidak Berwenang

Proteksi di Aplikasi

  • Gerbang Otentikasi: Pengguna tidak dapat melihat dashboard telemetri tanpa login dengan kredensial yang valid.
  • Visibilitas Sandi: Ikon intip sandi untuk menghindari kesalahan pengetikan di lapangan.
  • Penyimpanan Sesi Aman: Menggunakan penyimpanan lokal terenkripsi Android SharedPreferences.
  • Manajemen Sandi: Kata sandi bawaan dapat diubah kapan saja di menu Pengaturan.

Praktik Keamanan SNMP Jaringan

  • Kustom Community String: Mendukung string unik selain public untuk privasi OID.
  • Firewall Subnet Filtering: Di MikroTik, akses SNMP dapat dibatasi hanya untuk subnet IP teknisi.
  • Tanpa Bocoran Cloud: Tidak ada data perangkat yang diunggah ke server pihak ketiga manapun.

BAGIAN 6: TEKNOLOGI

Teknologi & Arsitektur Perangkat Lunak

Standar Pengembangan Modern Android Google (100% Kotlin)

Komponen Teknologi

  • Bahasa: Kotlin 100% (Modern, Type-Safe, Expressive).
  • UI Toolkit: Jetpack Compose & Material Design 3 (M3).
  • Pola Desain: MVVM (Model-View-ViewModel) + Repository Pattern.
  • Asinkron: Kotlin Coroutines & StateFlow.
  • Penyimpanan: Room SQLite Database (Lokal & Offline).
  • Protokol: Native UDP Datagram Socket & BER Decoder.

Desain Responsif (Adaptive Layout)

  • Mode Smartphone (Galaxy A10): Navigasi bawah (Bottom Navigation Bar) yang mudah dijangkau satu tangan.
  • Mode Tablet (Galaxy Tab A7 Lite): Panel navigasi samping (Navigation Rail) untuk produktivitas multi-panel.
  • Ukuran APK: Sangat ringkas (~15 MB) dan efisien dalam penggunaan baterai HP.

BAGIAN 7: ROADMAP

Kesimpulan & Rencana Pengembangan

Manfaat Nyata yang Dihasilkan dan Rencana Pembaruan Mendatang

Manfaat Utama yang Dicapai

  • Mobilitas Penuh: Teknisi dapat mengecek status kesehatan router langsung dari lapangan.
  • Tanggap Darurat Lebih Cepat: Notifikasi Telegram mencegah downtime berkepanjangan di kampus.
  • Multi-Vendor Universal: Menghemat waktu tanpa perlu berganti-ganti aplikasi vendor.

Rencana Masa Depan (Roadmap)

  • SNMP v3: Menambahkan otentikasi SHA-256 dan enkripsi privasi AES-128.
  • Auto Discovery: Pemindaian IP otomatis untuk mendeteksi seluruh perangkat dalam satu subnet.
  • Ekspor PDF: Pembuatan laporan rekap gangguan dan performa bulanan otomatis.
  • Home Screen Widget: Ringkasan status router langsung di layar depan HP.
